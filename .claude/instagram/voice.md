# Voice profile (read this before writing any Instagram content)

Three brands (OCC, Arunera, La Shaunnie). Ask which one if the request does not say. Never mix them.
Published text (scripts, captions, on-screen text, DMs): English only.
Chat with Vanessa: Traditional Chinese.

## OCC (Origin Coffee Crafter) — B2B specialty roaster, Cambodia wholesale
Audience: cafe owners, operators, buyers.
Voice: cold, objective, precise, data-driven. A calibrated laboratory, not an artisan studio.
Rules: radical brevity. Facts, specs, metrics only. No lifestyle fluff. No emotion.
Use: calibrated, specification, infrastructure, parameters, extraction, yield, volume,
systems, operators, consistency, supply chain, logistics, precision, metric, variance.
Never use: passion, love, cozy, journey, morning cup, handcrafted, magic, community,
vibes, delicious, heartwarming.
Example: "Every batch is strictly calibrated to specification. We eliminate variance so you can scale with reliability."

## Arunera — Cambodian luxury specialty coffee, Phnom Penh, tourists, later Western
Audience: locals, tourists, gift buyers.
Voice: short sentences, poetic but specific, discovery over explanation, restrained, confident.
Rhythm: short declarative, one longer detail sentence, short line that lands.
Never use: unique, authentic, artisanal, premium, special, perfect, amazing, handcrafted,
curated, journey, experience, elevate, indulge, delight, hidden gem, ancient, exotic, traditional.
Never: exclamation marks, rhetorical questions, "perfect for...", "We believe...",
"Discover...", "Welcome to...", similes that reach, claims without specifics.
Name: "Arunera" in text. Never lowercase, never all-caps mid-sentence.
Tagline "The Area of First Light": closing line only, used sparingly, never an opener.
Product: Guardian — Mondulkiri 12°N (tea-bag style, Mondulkiri Robusta).
Example: "Cambodia grows this. The Mondulkiri highlands, where altitude and red soil produce a Robusta unlike any other on the continent. One cup makes it obvious."
