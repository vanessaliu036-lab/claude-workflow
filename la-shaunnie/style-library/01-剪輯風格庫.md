## 一、參考影片拆解(16.3 秒,720×1280,30fps)

整支只有 4 個段落、3 次切換。**節奏不是靠剪點,是靠字幕一塊一塊換。**

| 時間 | 段落 | 畫面 | 字幕 |
|---|---|---|---|
| 0.0~1.3 秒 | 開場 Hook | 全螢幕人物,車內 | 置中偏下,3 個詞逐步長出來:`The richest` → `people`(斜體)→ `in the world` |
| 1.3~9.3 秒 | 分割畫面 | 上方人物裁切,下方整塊圖卡(圓餅圖,白底) | 白色圓角小字塊,放在人物和圖卡的交界線上,每次 1~2 個字 |
| 9.3~12.3 秒 | 重點句 | 回到全螢幕,人物拉近 | 靠左多行,逐字長出來,情緒詞用斜體 |
| 12.3~16.3 秒 | 結尾 | 畫面壓暗到約 25%,中央品牌圖示 | 圖示顏色變化,下方小字帳號名 |

### 字幕換塊的節奏(分割畫面段落)

| 時間 | 字幕塊 | 停留 |
|---|---|---|
| 1.3~2.7 | `are 75%` | 1.3 秒 |
| 2.7~3.3 | `entrepreneurs` | 0.7 秒 |
| 3.3~5.0 | `15% investors` | 1.7 秒 |
| 5.0~5.7 | `7%` | 0.7 秒 |
| 5.7~6.3 | `athletes` | 0.7 秒 |
| 6.3~7.7 | `3% artists` | 1.3 秒 |
| 7.7~8.7 | `and 0%` | 1.0 秒 |
| 8.7~9.3 | `employees` | 0.7 秒 |

平均每塊約 1 秒,範圍 0.7~1.7 秒。**數字永遠排在詞的最前面**(`15% investors`,不是 `investors 15%`),眼睛先抓到數字。

### 重點句的長出順序(9.3~12.3 秒)

`Nobody` → `ever` → `got rich`(斜體)→ `from` → `being` → `an employee`(斜體)。
整句長完後停 0.3~0.5 秒給觀眾讀,馬上轉結尾。

### 聲音(從音量曲線判斷)

- 人聲連續到約 12.1 秒,音量約 -14 到 -17 dB。
- 12.25 秒靜音約 0.25 秒,**12.5 秒出現一個比人聲大 7~10 dB 的收尾音效**,約 0.8 秒,14 秒前淡掉。
- 整支平均 -14.4 dB,沒有聽出明顯的背景音樂。

## 二、設計規格(可直接用)

### 字幕設計
1. **兩套字幕。** 開場和重點句用「編輯感」:襯線字體,情緒詞斜體。數據段落用「資訊感」:乾淨無襯線,放在圓角字塊裡。
2. **字塊小而準。** 字塊放在人物和圖卡交界,不蓋住人物的臉。
3. **逐字或逐詞長出來**,不是整句一次出現。
4. **斜體只用在 1~2 個情緒詞**,多了就沒有重點。

### 畫面設計
1. 圖卡佔下半部約 55~60%,人物上半部約 40~45%,人物裁到嘴巴到頭頂。
2. 圖卡是整塊靜止的,**動感全靠字幕塊更換**。
3. 重點句段落用「拉近」重新取景,和分割畫面形成對比。
4. 結尾壓暗畫面,讓品牌圖示成為唯一焦點。

### 節奏原則
- 段落少而分明:一支 16 秒只切 3 次。
- 字幕 0.7~1.7 秒換一塊。
- 關鍵段落結束前,先留一個很短的停頓,再給收尾音效。

## 三、套用到 La Shaunnie 的版本

| 項目 | 參考影片 | La Shaunnie |
|---|---|---|
| 襯線字體 | Playfair 類 | **Italiana**(官網標題字體) |
| 無襯線字體 | 窄體粗黑 | **DM Sans** 粗體 |
| 圖卡底色 | 白底 | 奶油白 `#F7F2EC` |
| 圖卡強調色 | 藍、綠、橘、紫 | 米金 `#CAB69B`、咖啡 `#514A44` |
| 字塊 | 白底黑字圓角 | 奶油白底、咖啡字、圓角,輕微陰影 |
| 情緒詞斜體 | 白色斜體 | Italiana 斜體,奶油白或米金 |
| 結尾 | 暗畫面加圖示 | 暗畫面加 LA SHAUNNIE 標誌,下方小字官網網址 |
| 結尾音效 | 收尾音效約 12.5 秒 | 結尾字卡出現的瞬間放一個「叮」 |

### 20 秒版本的時間分配(招募影片用)

| 時間 | 段落 | 做法 |
|---|---|---|
| 0.0~1.5 | Hook | 全螢幕,3 個詞逐步長出來,關鍵詞用 Italiana 斜體 |
| 1.5~12.0 | 分割畫面 | 圖卡每 2~3 秒換一張(比參考影片更快,因為我們只有 20 秒);字塊每 0.7~1.5 秒換一次 |
| 12.0~17.5 | 重點句 | 人物拉近,靠左多行逐字長出,2 個斜體詞 |
| 17.5~20.0 | 結尾 | 暗畫面、標誌、官網網址、「叮」 |
